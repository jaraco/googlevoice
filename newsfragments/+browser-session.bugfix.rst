Sending no longer asks you to sign in again. Chrome drops Google's login cookies from the browser profile on every clean exit, so ``BrowserSender`` (and ``python -m googlevoice send``) now signs the browser in from the saved ``session.json`` whenever the profile is signed out, pins those cookies so they survive the next exit, refreshes ``session.json`` on close, and quits Chrome cleanly instead of killing it. The saved session is only replaced by cookies that actually authenticate, is written atomically with owner-only permissions, and a Chrome that refuses to quit is killed rather than left holding the profile. A Google account with no Voice number now gets a clear error instead of a stalled send.
