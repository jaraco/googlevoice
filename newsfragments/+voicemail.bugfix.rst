``Message.text`` no longer returns an empty string for voicemails. Google leaves ``messageText`` empty on every voicemail and delivers the transcript as scored word tokens instead, so ``text`` now falls back to those words joined into a sentence, with the raw value available as ``transcript`` and its state as ``transcript_status`` / ``transcript_confidence``. ``Message.duration`` (the length of a call, voicemail or recording, in whole seconds) is now documented and included in ``as_dict()``.
